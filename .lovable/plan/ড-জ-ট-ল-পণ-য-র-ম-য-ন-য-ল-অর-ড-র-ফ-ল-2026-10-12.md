# ডিজিটাল পণ্যের ম্যানুয়াল অর্ডার ফ্লো

## ব্যবহারকারী যা দেখবেন
1. পণ্যের ডিটেইল পেজে "অর্ডার করুন" বাটন।
2. ছোট popup: নাম, email, WhatsApp নম্বর (ভুল হলে লাল বর্ডার + নিচে সতর্কবার্তা)।
3. পেমেন্ট ধাপ: bKash / Nagad / Rocket / Upay — নম্বর 01949085128 কপি বাটনসহ, টাকার পরিমাণ (ট), Transaction ID ও পাঠানো নম্বর লেখার ঘর।
4. জমা দিলে: Order ID (যেমন GD-XXXXXX) + "WhatsApp-এ যোগাযোগ করুন" বাটন (8801345407572, মেসেজে Order ID, পণ্য, দাম আগে থেকে লেখা)।
5. দাম সবসময় সার্ভারে নতুন করে হিসাব — ব্রাউজারের দাম বিশ্বাস করা হবে না।
6. Auto delivery / supplier থেকে স্বয়ংক্রিয় কেনা হবে না (ঝুঁকি)। মালিক হাতে যাচাই করে দেবেন।

## মালিকের জন্য
- Admin dashboard-এ "Digital Orders" তালিকা: pending / paid / delivered / cancelled স্ট্যাটাস বদলানো যাবে।

## Technical
- New table `digital_orders` (id, public_code, product_slug, product_name, amount_bdt, buyer name/email/whatsapp, payment_method, sender_number, trx_id, status, user_id nullable, timestamps). RLS on; no anon select; inserts only via server function; admin read/update via existing `assertAdmin`.
- `src/lib/digital-orders.functions.ts`: `createDigitalOrder` (public, Zod-validated, rate-limited per IP, server-side price via `retailPriceBdt` + live/cached Canboso price, rejects out-of-stock), `listDigitalOrders` / `updateDigitalOrderStatus` (admin).
- `src/components/ghost/DigitalOrderDialog.tsx` (lazy-loaded, reuses BuyDialog styling + `purchase-contact.ts` validation).
- Wire into `src/routes/digital/$slug.tsx`; admin section in existing admin dashboard.
- Daily stock refresh stays out of scope (separate approval).
