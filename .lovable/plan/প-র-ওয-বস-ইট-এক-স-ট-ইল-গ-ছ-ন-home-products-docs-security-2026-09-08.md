# পুরো ওয়েবসাইট এক স্টাইলে গোছানো (Home + Products + Docs + Security)

## এখন সমস্যা কী

- হোম পেজ নতুন HTML ডিজাইন (হালকা ব্যাকগ্রাউন্ড, ক্যাপসুল নেভিগেশন, নিজস্ব Ask Ghostae AI বাটন) ব্যবহার করে, কিন্তু এতে কোনো ফুটার নেই এবং প্রোডাক্ট/ফিচার/FAQ সেকশনও নেই।
- Products, Docs, Security, Blog, Checkout পেজগুলো পুরোনো শেল ব্যবহার করে — আলাদা হেডার, আলাদা ফুটার, পুরোনো সাহায্য বাটন ও পুরোনো AI বাটন। তাই হোম থেকে ওই পেজে গেলে হেডার-ফুটার হঠাৎ বদলে যায়।
- ফলে দুটি আলাদা ডিজাইন সিস্টেম একসাথে চলছে, রঙও মেলে না।

## সমাধানের দিক

একটাই ডিজাইন থাকবে — হোম পেজের নতুন স্টাইল। ওই হেডার আর একটি নতুন ম্যাচিং ফুটার সব পেজে বসবে।

### ১. শেয়ার্ড হেডার
- হোমের ক্যাপসুল নেভিগেশন হুবহু একটি রিইউজেবল হেডারে রূপ নেবে (Home / Products / Docs / Security + প্রোফাইল বাটন)।
- যে পেজে আছেন সেটি নীল ক্যাপসুলে সাদা লেখায় হাইলাইট হবে।
- মোবাইলে নেভিগেশন মেনু কাজ করবে।
- ডার্ক মোড ও ভাষা বাটন আগের সিদ্ধান্ত অনুযায়ী লুকানোই থাকবে।

### ২. শেয়ার্ড ফুটার (নতুন, একই স্টাইল)
- হালকা ব্যাকগ্রাউন্ড, একই নীল অ্যাকসেন্ট, চার কলাম: Brand, Products, Resources, Company।
- শুধু যেসব পেজ সত্যিই আছে সেগুলোর লিংক থাকবে (Products, Text, Docs, Security, Blog)। যেগুলো নেই সেগুলো বাদ যাবে বা তৈরি হবে — ভাঙা লিংক থাকবে না।
- WhatsApp community ও কনট্যাক্ট, কপিরাইট লাইন।
- এই ফুটার হোম পেজেও যুক্ত হবে।

### ৩. Ask Ghostae AI একটাই থাকবে
- হোমের HTML-এর ভিতরের সুন্দর লঞ্চারটাই সব পেজে ব্যবহার হবে; পুরোনো সাহায্য বাটন ও ডুপ্লিকেট অ্যাসিস্ট্যান্ট সরে যাবে।

### ৪. হোম পেজে missing সেকশন যোগ
হোমের নিজের স্টাইলেই, HTML-এর অ্যানিমেশন নষ্ট না করে, নিচে ক্রমান্বয়ে:
1. Products showcase — GHOSTAE Text (লাইভ), Caption, এবং বাকি প্যানেলগুলো "Coming soon" কার্ডে।
2. কেন Ghostae — সংক্ষিপ্ত ৩-৪টি হাইলাইট।
3. Device compatibility + System check (যেটা এখন আছে, স্টাইল মিলিয়ে)।
4. ছোট FAQ।
5. ফুটার।

### ৫. রঙ ও স্পেসিং মিল
- সব পেজে একই হালকা ব্যাকগ্রাউন্ড, একই কার্ড বর্ডার/শ্যাডো, সেকশনগুলোর মাঝে যথেষ্ট দূরত্ব।
- প্রোডাক্ট, Docs, Security পেজের ভেতরের কনটেন্ট অপরিবর্তিত থাকবে — শুধু বাইরের হেডার/ফুটার/রঙ এক হবে।

## যা বদলাবে না
- GHOSTAE Text প্রোডাক্ট পেজের ভিতরের HTML সেকশন, প্রাইসিং, লাইসেন্স পপআপ, ডাউনলোড ফাইল — সব আগের মতোই।
- অ্যাডমিন প্যানেল এই কাজের বাইরে।

## টেকনিক্যাল নোট
- `src/content/home-page/page.ts`-এর header markup থেকে একটি `SiteHeader` কম্পোনেন্ট তৈরি; হোমের HTML থেকে header block বাদ দিয়ে ওই কম্পোনেন্ট ব্যবহার হবে (অ্যানিমেশন/CSS অপরিবর্তিত, `.gh2` scope রক্ষা)।
- `src/components/ghost/Shell.tsx` (`GhostShell`)-কে নতুন হেডার + নতুন `SiteFooter` দিয়ে rebuild; সব রুট আগের মতোই `GhostShell` ব্যবহার করবে, তাই রুট ফাইলে বড় পরিবর্তন লাগবে না।
- `HelpFab` সরানো হবে; `SiteAssistant` শুধু একবার `__root.tsx`-এ মাউন্ট হবে (হোমের ইনলাইন লঞ্চারের সাথে সংঘর্ষ এড়াতে একটাই বাস্তবায়ন রাখা হবে)।
- হোমের নতুন সেকশনগুলো আলাদা lazy কম্পোনেন্টে থাকবে যাতে লোডিং দ্রুত থাকে।
- ফুটার লিংকের জন্য অনুপস্থিত রুট (যেমন privacy/terms/contact) হয় তৈরি হবে, নয়তো লিংক বাদ যাবে — টাইপচেক ভাঙবে না।
