ইনস্টলেশন গাইড Installation Guide

আপনার অপারেটিং সিস্টেম নির্বাচন করুন এবং নিচের ধাপগুলো অনুসরণ করুন: Select your operating system and follow the steps below:

1
আনজিপ: Ghostae Text v1.0 জিপ ফাইলটি ডাউনলোড করে সম্পূর্ণ Extract করুন। Unzip: Download and extract the Ghostae Text v1.0 zip file completely.
2
ইনস্টল: ফোল্ডারের ভেতর Windows/Install.bat ফাইলে ডাবল-ক্লিক করে রান করুন। Install: Double-click and run the Windows/Install.bat file inside the folder.
3
অপেক্ষা করুন: কনসোল স্ক্রিনে "Installation complete!" না আসা পর্যন্ত অপেক্ষা করুন। Confirmation: Wait until you see the "Installation complete!" confirmation message.
4
প্লাগইন চালু: After Effects ওপেন করে মেনু থেকে যান: Window → Extensions → Ghostae Text। Open Panel: Launch After Effects and go to: Window → Extensions → Ghostae Text.
1
আনজিপ: ফাইলটি আনজিপ করে আপনার Downloads ফোল্ডারে রাখুন। Unzip: Extract the folder and ensure it is placed directly in your Downloads directory.
2
টার্মিনাল কমান্ড: Terminal অ্যাপটি খুলে নিচের কোডটি পেস্ট করে Enter দিন: Terminal Command: Open Terminal, paste the following command, and press Enter: 
mkdir -p ~/Library/Application\ Support/Adobe/CEP/extensions
cd ~/Downloads/Ghostae\ Text\ v1.0
cp -R com.ghost.text ~/Library/Application\ Support/Adobe/CEP/extensions/
3
Gatekeeper অনুমতি: ম্যাক যদি প্লাগইন খুলতে বাধা দেয়, তবে এই কমান্ডটি চালান: Gatekeeper Bypass: If macOS security blocks the plugin, run this command: 
xattr -rd com.apple.quarantine ~/Library/Application\ Support/Adobe/CEP/extensions/com.ghost.text
4
প্লাগইন চালু: After Effects ওপেন করে যান: Window → Extensions → Ghostae Text। Open Panel: Launch After Effects and go to: Window → Extensions → Ghostae Text.

💡 পরামর্শ: Tip: প্রথমবারে তালিকা না দেখালে After Effects পুরোপুরি বন্ধ করে আবার চালু করুন। If the extension is not visible immediately, restart After Effects.
