INSTALLATION
- Self-contained Windows installer: Install-GhostaeText.cmd
- Uninstall: Uninstall-GhostaeText.cmd
- The installer validates the v3.41.0 manifest and release bundles, stages/copies atomically, backs up an existing installation, and configures the current-user CEP runtime as needed for this unsigned package.
Compatibility:
- Manifest-declared After Effects host range: 16.0–99.9 (AE 2019 and later host versions within that declared range).
- Best overall compatibility: AE 2025 (25.x), AE 2026 (26.x), and later 25+ releases.
- Perfect Color Presets: require AE 2025 (25.x) or newer.
- Older supported builds below 25.x: other sections may work, but feature behavior/results may vary.
