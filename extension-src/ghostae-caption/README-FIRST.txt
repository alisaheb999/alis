================================================================
  GHOSTAE CAPTION  1.2.3   -   After Effects Auto Caption Panel
================================================================

WINDOWS
-------
1. এই ZIP টা পুরোপুরি Extract করুন (Right click > Extract All)
2. After Effects বন্ধ করুন
3. "Install Ghostae Caption (Windows).cmd" ফাইলটি double click করুন
4. Install complete লেখা আসলে After Effects চালু করুন
5. Window > Extensions > Ghostae Caption

  Install fail হলে: installer টায় right click > "Run as administrator"
  Log ফাইল: %TEMP%\ghostae-caption-install.log

MAC
---
1. ZIP extract করুন
2. After Effects বন্ধ করুন
3. "Install Ghostae Caption (Mac).command" এ right click > Open
4. After Effects চালু করে Window > Extensions > Ghostae Caption

  "cannot be opened" এলে Terminal এ:
     chmod +x "Install Ghostae Caption (Mac).command"

UNINSTALL
---------
Windows : Uninstall Ghostae Caption (Windows).cmd
macOS   : Uninstall Ghostae Caption (Mac).command
