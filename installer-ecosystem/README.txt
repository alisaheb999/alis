GHOSTAE ECOSYSTEM - After Effects
==================================

WHAT IS INSIDE
  panels\com.ghost.cache      Ghostae Cache    - asset library
  panels\com.ghost.text       Ghostae Text     - text/style/animation + Auto Caption
  panels\com.ghost.presets    Ghostae Presets  - preset + colour library
  panels\com.ghost.bridge     Ghostae Breeze   - browser-to-AE bridge (when included)
  tools\Ghost-Caption-Worker.zip  Chrome helper for Ghostae Text Auto Caption
  tools\Ghostae-VPS-Agent.zip     Chrome/VPS browser automation companion

SAFETY
  This ZIP contains CEP panel source files and simple copy installers only.
  No hidden downloader, encoded PowerShell, bundled .exe, or remote executable
  is required. If Windows shows a warning, verify the matching .sha256 file
  from ghostae.com before installing. A paid code-signing certificate is the
  long-term way to reduce unsigned-app false positives further.

INSTALL
  Windows : double-click Install-Ghostae-Ecosystem.cmd
            silent mode  ->  Install-Ghostae-Ecosystem.cmd /S
  macOS   : ./Install-Ghostae-Ecosystem.command

Then restart After Effects and open:
  Window > Extensions > Ghostae ...

LICENCE
  Enter your licence key in ANY panel once. The activation is cached
  machine-wide, so every other Ghostae panel unlocks automatically.
  Device count and per-panel monthly limits follow your plan.

UNINSTALL
  Windows : Uninstall-Ghostae-Ecosystem.cmd
  macOS   : delete the com.ghost.* folders from
            ~/Library/Application Support/Adobe/CEP/extensions
